## 今天有点干劲

兜过风的小鹈鹕，这次想跑起来。还是米色长发、蓝眼睛和白色外套，只是手里多了一把朝向身后的电锯。举过头顶，迈开步子，烦恼就留在后面吧。

## 一起跑一会儿

拖动「狂奔节奏」滑块，可以在 **0–3 倍速**之间调节。调到 0 就停在这一刻，按下「暂停」可以歇一会儿，再继续出发。

慢慢跑时，双腿交替迈步，小腿向后收起，再往前伸展。速度加上去，抬腿幅度和步频也跟着变大；再快一点，清晰的双腿会渐渐化成带着弧形残影的椭圆旋风，像小时候动画片里的夸张跑步。

往回拖动滑块，旋风也会慢慢变回双腿。头发、衣摆、脚边的尘土和身后的速度线，一起跟着节奏走。

## 小小制作记

角色、电锯和场景都由 SVG 绘制，用 JavaScript 串起动作。大腿与小腿始终连接在同一个膝关节点上，再用缓动、模糊和残影，让迈步自然过渡到旋风腿。

不依赖外部图片或动画库，下载 HTML 后也可以离线打开。作品也会跟随博客的「暂停动效」开关停下来，留一张安静的画面。
